## Read-only acknowledged-job reconciliation

`horde_reconciliation.py` accepts only the existing Diane target. It verifies the
original ledger, receipt and prompt byte hashes, and binds to the recorded ID:

`599f7b74-f21a-4244-b92e-97bfa752d343`.

It does not recompile that old job using repaired semantics. It preserves the old
contract/prompt hashes, model, credit obligations and blocked publication status.
Its transport rejects every method except GET and every path except the exact
acknowledged job's `/v2/generate/check/<id>` and `/v2/generate/status/<id>`, before
forwarding any request. Payloads, POST generation, DELETE cancellation, foreign IDs,
provider switching, reservations and new seeds have no reconciliation path.

Each invocation appends a uniquely named record under
`output/phase-d2r/Ep104/reconciliation/`; it never overwrites the original D.2
ledger, receipt, prompts, hashes, rejected hero, review or benchmark reports.

The states are:

- `REMOTE_STATE_UNRESOLVED`: queued/running, transient GET error, malformed or
  inconsistent response, missing/expired record, unverified model/result/content.
  This never permits regeneration. A 404 does not prove failure or cancellation.
- `REMOTE_JOB_SUCCEEDED`: strict terminal check/status, exactly one result,
  exact Albedo model, uncensored healthy content, returned seed and valid nonuniform
  1024-square raster. Result bytes/pixels are stored separately with hashes. No
  visual approval or composition is implied.
- `REMOTE_JOB_TERMINAL_FAILURE`: the existing Horde parser provides affirmative
  terminal failure evidence. Absent a recorded cancellation acknowledgement,
  an empty/deleted job is unresolved; cancellation is not inferred.

Repeated reconciliation reads are allowed. The command has no automatic polling
loop or generation retry. CLI exit is 1 for unresolved/input error, 0 for an
affirmatively resolved remote terminal state. A terminal failure is reported as
failure even with exit 0 because the reconciliation itself resolved the state.

```sh
python -m src.phase_d2_benchmark --repair-preflight
python -m src.phase_d2_benchmark --reconcile-job 12
```

Old D.2 package preflight/report functions refuse mutation of the archive. The
generation CLI is suspended pending a separately authorised/reviewed new run.
Error reporting no longer rewrites the old benchmark report.
