# R2.2d — Source-grounded enrichment with stable portrait geometry

11 November 2026 | Automation repository ONLY | stacked on draft PR #6.

## User direction and boundary

The user welcomed the R2.2c positioning and requested enrichment, not a layout restart. Original portrait coordinates, proportional cover crops, main phrase apertures, 1080x1350 format and publication furniture are unchanged. This is a historical Ep136 regression exercise, not fresh reporting or accepted episode replacement. The source is the archived 4 November 2026 Slide Design; its older format notes are historical, while active v3.1 supplies 4:5 output.

The Manual directory and accepted archives remain read-only. Current production guidance was reread on 11 November. Its 12 November-only faithful-regeneration exception is NOT invoked here: these proofs retain exact source assets. The newer full-frame visual-art standard remains a later aesthetic target; this increment respects the user-reviewed placement baseline rather than claiming the fixed layout is already final.

## Implementation

- `v3_scene_enrichment.py`: two deterministic, explicitly schematic visual-family recipes. The control map gains clipped relief engraving, delineated access strata, leader lines and a raised drafting surface. The sovereignty wheel gains five source-labelled engraved rings, physical depth, ruled edges and restrained blue/gold accents. No new locations, vote counts or geopolitical claims are invented; the relief is not a surveyed map.
- `v3_takeaway_rail.py`: restores all three exact `takeaway_ideas` strings in existing headline whitespace as open typography, not filled cards. Fails on collision or overflow rather than rewriting copy. It compares every pixel outside the permitted rail with the base exported PNG, updates the output SHA and preserves the source-identity proof.
- `v3_enriched_proof.py`: reads the historical Manifest and original hashed Nora/Amari/Ep128 files, renders two isolated nonpublishable proof PNGs and external QC receipts. Requires an empty output directory. No providers, network, publishing, private-asset GitHub uploads or Drive writes.
- No changes to the previously tested compositor, historical proof runner or closed Manifest schema. All enrichment is an opt-in automation layer.

## Validation observed locally

Thirteen new offline regression cases passed. Genuine-asset proofs were rendered and opened for visual inspection. Opaque canonical portrait pixels verify for Nora and Amari. Exact source takeaway strings are present and bound by SHA-256. Post-takeaway pixels outside the reserved rail are unchanged. Both are 1080x1350 RGB PNGs and remain `HUMAN_REVIEW_REQUIRED`, with no publication authorisation.

Local environment used available Pillow 12.3.0 in an isolated workspace. The attempted isolated installation of pinned Pillow 11.3.0 could not access package networking; no user/global dependencies were changed. GitHub CI is configured separately for Python 3.12, Pillow 11.3.0 and pytest 8.4.1; do not assert identical PNG bytes across different runtime/font builds. CI result must be observed before calling this code verified on that pinned runtime.
