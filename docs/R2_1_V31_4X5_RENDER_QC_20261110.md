## Reconciliation decisions

1. Active carousel final = **ten independent 1080 × 1350 PNGs (4:5)**; rejected historical `1080 × 1440` images must not be stretched into current output. Reel remains six `1080 × 1920` PNGs.
2. Manifest v2 remains **closed**, including exact JSON delimiters and all existing fields. Rendering and QC information belong in separate receipts.
3. Masthead `AI GEOPOLITIC`, episode/full date, exactly one two-digit `XX/10` counter, exactly ten equal-baseline dots (one filled), and full footer are deterministic production furniture. No ten separate mini-counters.
4. One panelist's exact canonical source pixels, or two in an authorised dual, must be preserved through alpha-aware proportional compositing. Face and costume regeneration/recolouring are forbidden.
5. Ep128 remains primary artistic authority. Accepted Ep142 reels are **secondary technique-only references** for dimensional/tactile scenes and physically integrated lettering; their incorrect or outdated furniture does not become the canonical standard.
6. Design integrity PASS is an **input gate only**. Every real exported image starts `RENDER_QC_PENDING`, must be opened/inspected and receive a separate external QC receipt. The QC status can be `RENDER_QC_FAIL`, `HUMAN_REVIEW_REQUIRED`, or `RENDER_QC_PASS`; never derive PASS from a generator message or good prompt.
7. Frame 01 is a distinct 9:16 reel pilot; its method must pass independent render integrity before the other five are produced.
8. Publication and accepted archive writes require their own user authorisation; neither is enabled by the R2.1 compositor or QC checker.

## Implemented in R2.1

- `src/v3_compositor.py`: reflows separate headline, hero, explanatory and footer regions for native 1080 × 1350 rather than resizing the old 1080 × 1440 raster; creates a single `XX/10` counter.
- `src/v3_render_qc.py`: opens actual exported PNG bytes, measures dimensions, checks the compositor source/output hash, expected counter and pagination, and requires separately recorded reviewer identity and SHA-bound image-level evidence before an external `RENDER_QC_PASS`. It never marks the asset publishable, and it never changes Manifest v2.
- `tests/test_v3_compositor.py` and `tests/test_v3_render_qc.py`: scoped pure tests for valid 4:5, rejection of 3:4, real exported bytes, wrong hashes, missing inspection, incomplete or failed review, all ten slide positions, alpha sources, dual casting and type overflow.
- `.github/workflows/r2-v3-compositor-qa.yml`: isolated GitHub Actions regression, with a short-lived **synthetic, nonpublishable** image artifact for visual inspection; no generators, private Drive assets, publishing, manual-ledger writes or OAuth keys.

## Remaining R2.2 / R2.3 risks

This first compositor still reserves fixed header, hero and text regions; **it is not yet the adaptive bespoke, material-integrated editorial compositor that can match Ep128 plus scoped Ep142 craft**. Human-authored background-human-free review is not automatic face detection. Source PNG hashes verify input bytes but do not by themselves prove every displayed portrait pixel stayed visually unaltered after scaling.

Before R2 can be considered visually accepted:
- Inspect a real emitted 4:5 synthetic compositor proof for clipping, hierarchy, exact counter/dot rail, material-integration quality and legibility. Record deficiencies instead of claiming a style PASS.
- Expand composition plans into a few argument-responsive arrangement families, rather than replacing every hero with the same box.
- Develop an integrated typography method on pre-reserved tactile surfaces; do not force a flat card over a complete illustration.
- Build a **genuine** one-panelist and one authorised dual-panelist pre-publication proof against selected real approved portraits and human-approved bespoke backgrounds.
- Implement image-level caption/source-fact review, separate reel 9:16 pilot, per-item review artifacts and batch continuity checks.
