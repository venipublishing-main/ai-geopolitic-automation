# Milestone 2 Add-on

This package upgrades the clean repository from the generic test card to a first code-rendered AI Geopolitic slide prototype.

It adds:

- the six locked portraits
- machine-readable brand, character and layout rules
- the upgraded production specification
- a structured sample slide input
- a reusable prototype renderer
- a manual GitHub Action
- basic automated tests

## Run in GitHub

1. Add these files to the repository, preserving their folder paths.
2. Open **Actions**.
3. Select **Render Milestone 2 prototype**.
4. Run the workflow.
5. Download the artifact named `ai-geopolitic-milestone-2-prototype`.

The output is a fidelity prototype, not the final 20-slide engine. We will review it against the supplied episode references before creating more layouts.
